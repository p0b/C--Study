# 练习 5：大文件单词统计 (分而治之)

## 场景描述
处理一个远超内存容量限制（模拟 10GB）的巨型文本文件，统计出现频率最高的 Top 10 单词。

## 技术要求
- **哈希分流**：使用 `std::hash` 对单词进行分片，确保相同单词进入同一分片文件。
- **内存控制**：确保单次内存占用不超过预设阈值（模拟 2GB）。
- **文件 IO**：高效读写大文件。
- **数据结构**：使用 `std::unordered_map` 进行局部计数，使用 `std::priority_queue` (堆) 筛选 Top 10。

## 提示步骤
1. **生成大文件**：编写脚本生成测试数据。
2. **第一阶段 (Map)**：扫描大文件，按哈希值分流到 10 个小文件中。
3. **第二阶段 (Reduce)**：遍历每个小文件，统计词频并记录该文件的 Top 10。
4. **第三阶段 (Merge)**：合并所有小文件的结果，得出最终 Top 10。

## C++ 知识点
- 文件流操作 (`std::ifstream`, `std::ofstream`)
- 哈希函数应用
- 容器与算法的综合运用
