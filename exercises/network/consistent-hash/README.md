# 练习 3：分布式一致性哈希

## 场景描述
模拟 Redis 集群扩容场景。我们需要实现一个一致性哈希算法，支持节点的添加、删除，并统计数据迁移率。

## 技术要求
- **核心数据结构**：使用 `std::map` (红黑树) 存储哈希环，利用其有序性进行顺时针查找。
- **虚拟节点**：每个物理节点映射为 N 个虚拟节点，解决数据倾斜。
- **哈希算法**：使用简单的 `std::hash` 配合 Salt 模拟。

## 验证方法
1. 初始化 5 个物理节点，每个节点 100 个虚拟节点。
2. 生成 100,000 个随机 Key，记录它们分布在哪个物理节点上。
3. 增加 5 个新节点（扩容到 10 台）。
4. 再次计算这 100,000 个 Key 的归属。
5. 统计：有多少 Key 的归属发生了变化？（理想情况下，应该只有约 50% 的数据需要迁移）。

## C++ 知识点
- `std::map` 的使用 (insert, upper_bound)
- `std::string` 拼接与处理
- 类的封装与接口设计
