# 练习 1：布隆过滤器基础实现

## 场景描述
你需要实现一个布隆过滤器（Bloom Filter），用于快速判断某个元素是否存在于海量数据集中。这是一个空间效率极高的概率型数据结构，常用于垃圾邮件过滤、URL去重、缓存穿透防护等场景。

## 技术要求
- **核心原理**：理解并实现位数组（Bit Array）和多重哈希映射。
- **基本操作**：实现 `add`（添加）和 `might_contain`（查询）方法。
- **数学基础**：理解参数 $m$（位数组大小）和 $k$（哈希函数个数）的计算公式。
  - $m = - \frac{n \ln P}{(\ln 2)^2}$
  - $k = \frac{m}{n} \ln 2$
- **工程技巧**：使用双重哈希（Double Hashing）策略模拟多个哈希函数，避免计算开销。
  - $hash_i(x) = (hash_a(x) + i \times hash_b(x)) \pmod m$

## 提示步骤
1. **设计类结构**：确定 `std::vector<bool>` 作为位存储，定义 $m, k$ 等成员变量。
2. **实现构造函数**：根据预期元素数量 $n$ 和 误判率 $P$，自动计算最优的 $m$ 和 $k$。
3. **实现哈希策略**：实现基于 `std::hash` 的双重哈希逻辑。
4. **实现添加与查询**：完成 `add` 和 `might_contain` 的位操作逻辑。
5. **验证测试**：编写测试用例，验证功能正确性并统计实际误判率。

## 验证方法
1. 插入 1000 个已知字符串。
2. 查询这 1000 个字符串，预期结果应全部为 `true`。
3. 查询 1000 个**未插入**的字符串，统计返回 `true` 的个数（假阳性数）。
4. 计算实际误判率（假阳性数 / 总查询数），并与预设的 $P$ 进行对比。

## 预期成果
- 一个完整可用的 `BloomFilter` C++ 类。
- 一个能够展示插入、查询和误判率统计的测试程序。
- 深刻理解"为什么布隆过滤器不支持删除"以及"为什么会有误判"。
