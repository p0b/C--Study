- **`std::map::lower_bound`**：查找有序容器中不小于给定值的第一个元素。

- **RAII 与内存泄漏**：深刻理解 `new` 出来的对象必须在析构函数中 `delete`，否则就是“始乱终弃”。
- **`std::mt19937` 与 `uniform_int_distribution`**：现代 C++ 生成高质量伪随机数的方法。
- **STL 容器进阶**：
  - `vector::reserve()`：预分配内存，避免频繁重分配的性能神器。
  - `vector::at()`：比 `[]` 更安全的访问方式（带越界检查）。
  - `vector.clear()`：清空元素但保留容量。
- **运算符重载 (Operator Overloading)**：
  - `operator<`：自定义结构体的大小比较规则（用于堆排序）。
  - `operator+` / `operator[]` / `operator<<`：让自定义类型用起来像内置类型一样自然。
- **智能指针**：`std::unique_ptr` 用于管理独占资源（如文件流），禁止拷贝，只能移动。

## 会话记录：创建型设计模式（单例与工厂）

### 会话概览
- **主题**：创建型设计模式 (Creational Design Patterns)
- **核心内容**：单例模式 (Singleton)、工厂方法模式 (Factory Method)
- **目标**：理解对象创建与使用的解耦，掌握 C++ 中实现这些模式的最佳实践（语法细节）。

### 核心知识点

#### 1. 单例模式 (Singleton Pattern)
- **核心定义**：保证一个类只有一个实例，并提供全局访问点。
- **最佳实践**：Meyers' Singleton (局部静态变量法)。
- **代码解析**：
  ```cpp
  class Singleton {
  public:
      static Singleton& getInstance() {
          static Singleton instance; // 魔法：线程安全，首次调用初始化，程序结束自动析构
          return instance; // 返回引用，避免拷贝
      }
      Singleton(const Singleton&) = delete; // 🚫 禁止拷贝构造
      Singleton& operator=(const Singleton&) = delete; // 🚫 禁止赋值操作
  private:
      Singleton() {} // 🔒 构造函数私有化
  };
  ```
- **关键语法点**：
  - `static` 局部变量：解决线程安全争抢问题，自动管理生命周期。
  - `&` 引用返回：返回对象本尊，而非副本。
  - `= delete`：C++11 新特性，显式禁用编译器自动生成的函数。

#### 2. 工厂方法模式 (Factory Method)
- **核心思想**：定义创建对象的接口，让子类决定实例化哪一个类。
- **解决痛点**：符合**开闭原则**（Open/Closed Principle）。新增产品（如“榴莲披萨”）时，无需修改现有工厂代码，只需新增子类。
- **核心机制**：**多态 (Polymorphism)**。
- **关键语法点**：
  - `virtual void func() = 0;`：纯虚函数，定义抽象接口 (Interface)。
  - `virtual ~Base() {}`：虚析构函数，防止父类指针删除子类对象时的内存泄漏。

### 遇到的语法难点与解答
- **`static Singleton instance`**：为什么写在函数里？
  - 答：利用 C++ 标准保证的静态局部变量初始化特性，既实现了懒加载，又保证了线程安全。
- **`Singleton(const Singleton&) = delete`**：
  - 答：防止用户写出 `Singleton a = Singleton::getInstance();` 从而克隆出一个新对象，破坏单例唯一性。
- **`virtual` 的作用**：
  - 答：运行时动态绑定的开关。没有它，指针是谁就调谁的方法；有了它，指针指向谁（真实对象）就调谁的方法。
