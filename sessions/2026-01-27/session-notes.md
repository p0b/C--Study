## 遇到的问题与解决方案

### 1. 一致性哈希的顺时针查找
- **理解难点**：如何在哈希环上找到“第一个大于等于”Key 哈希值的节点。
- **解决方案**：利用 C++ `std::map` 的红黑树有序性，使用 `lower_bound` 查找。处理“回绕”逻辑：若 `lower_bound` 返回 `end()`，则取 `begin()`。
- **教学互动**：大王精准识别出 `nodes.empty()` 判空的重要性，避免了程序崩溃。

### 2. URL 去重系统的统计 Bug
- **找茬环节**：在“保安大叔 + 前台小姐姐”模型中，漏掉了对数据库二次确认次数的统计。
- **解决方案**：大王慧眼如炬，指出 `db_checks++` 应该在进入第二道防线时立即触发。

## 新学到的 C++ 语法/概念
- **`std::map::lower_bound`**：查找有序容器中不小于给定值的第一个元素。
- **`static` 随机数生成器**：优化性能，避免重复种子带来的随机性失效。
- **RAII 与内存泄漏**：深刻理解 `new` 出来的对象必须在析构函数中 `delete`，否则就是“始乱终弃”。
- **`std::mt19937` 与 `uniform_int_distribution`**：现代 C++ 生成高质量伪随机数的方法。
- **STL 容器进阶**：
  - `vector::reserve()`：预分配内存，避免频繁重分配的性能神器。
  - `vector::at()`：比 `[]` 更安全的访问方式（带越界检查）。
- **运算符重载 (Operator Overloading)**：
  - `operator+`：让自定义类型（如复数）支持加法运算。
  - `operator[]`：让对象像数组一样被访问。
  - `operator<<`：让自定义类型能直接被 `cout` 输出。
